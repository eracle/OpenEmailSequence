Create Campaign
===============

The Campaign creation page looks like this:

.. image:: ../../images/campaign_creation.png
  :width: 600
  :alt: Add Campaign page

When you create a campaign, you need to decide if the related sequences will be deleted along with the campaign, using the ``Delete sequences`` field.

Here you will find an inline creation or edition for ``Sequences`` this will not include the ``QUERY SET RULES`` section. It will only allow you to change the mail content in the Sequence.

Campaigns will allow you to manage many Sequences that need to be related between them.
